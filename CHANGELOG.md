# Changelog

## 2026-11-10 · public-content guard and Nivela numbers

- Nivela numbers updated from the real repository on 2026-11-10, rounded down: ~200k lines of
  Python, 300 domain services, 185 migrations, 330+ test files (case page and home stats, PT and EN).
- `docs/CONTENT.md` gains "Public site: what never goes here" (no IPs, internal hosts, CI machines,
  credentials, personal e-mails or customer data).
- New "public content" unit test fails the build if any site text matches those patterns.
- `AGENTS.md` (+ `CLAUDE.md`) with the rules for AI agents working on this public repository.

## 2026-11-04 · Repara

- New own product on the site: **Repara**, for authorized repair centers. Page `/pt/cases/repara/`
  and `/en/cases/repara/` with challenge, solution, stack and outcome, four videos and three
  screens recorded with demo data; card on the home page, marked "in development".
- `ReparaMark` wordmark and the `--color-repara` amber token. `VideoShowcase` takes the address
  shown in the browser bar.
- The previous custom-system case and its placeholder page are removed.

## 2026-11-04 · mobile layout

- Header fits 320px: short contact label on phones ("Contato" / "Contact"), no wrapping, logo
  dots clear of the theme button, 36px language link.
- Home: "common × SulCore" table becomes one column on phones; last Nivela stat spans the row;
  case card tops wrap; headings scale with the viewport (`clamp`).
- Touch targets of at least 24×24px in the footer, case page, contact composer and 404.
- `.label` letter-spacing 0.16em below 640px.
- New `tests/e2e/mobile-layout.spec.ts`: overflow, spilled text, target size and one-line
  button labels at 320, 360 and 390px on every page.

## 2026-11-04 · how this site is built

- New page `/pt/build/` and `/en/build/` with numbers generated by the pipeline (tests,
  Lighthouse per URL, page weight, LCP, workflows, ADRs, versions). Linked from the footer and
  the process section. ADR-0009.

## 2026-11-04 · supply chain

- Actions pinned by commit SHA; least-privilege permissions; checkout without persisted credentials.
- CodeQL (code and workflows), OpenSSF Scorecard, dependency review and `npm audit` in CI.
- `scripts/serve.mjs` replaces the `serve` package in tests. ADR-0008.

## 2026-11-04 · SEO and 404

- Sitemap with `hreflang`, robots.txt, canonical URLs, Open Graph/Twitter tags and Organization JSON-LD.
- Share image per language (`/pt/og.png`, `/en/og.png`) generated at build time.
- Branded, bilingual 404 page. ADR-0007.

## 2026-11-04 · quality gates

- ESLint (Next.js + TypeScript) and Prettier in CI; hooks issues fixed with `useSyncExternalStore`.
- WCAG 2.1 AA checks with axe on every page and both themes; contrast fixed at token level.
- Lighthouse CI with minimum scores. ADR-0006.

## 2026-11-04 · tests

- Unit tests (Vitest) for the demo state machine, the WhatsApp message and the content contract.
- End-to-end tests (Playwright) on desktop and mobile against the exported site; new CI job.
- Logic extracted to `src/lib/`; lockfile on npm 11. ADR-0005.

## 2026-11-04

- Dark theme (brand navy) is now the default, with a light/dark toggle in the header; the choice is remembered.
- "Why SulCore" section and team bios rewritten to talk about SulCore, not past employers; roles shown as "Developer".

## 2026-11-03

- Repository renamed to `sulcore/sulcore.github.io`; the site now lives at https://sulcore.github.io/.
- Dependencies updated (Next.js 16.4.3, React 19.3, Tailwind CSS 4.3, TypeScript 7) and GitHub Actions bumped to current majors.
- `@types/node` pinned to the Node 22 runtime; CI runs once per pull request.

- Repository opened to the public, with license, docs and decision records.
- Deploy to GitHub Pages through GitHub Actions; CI on every pull request.
- `verify-build` checks the exported site (required pages, internal links, `hreflang`).
- Base path support so the site works under `sulcore.github.io/<repo>/` or on its own domain.
- Footer link to this repository.
